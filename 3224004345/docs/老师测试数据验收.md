在项目根目录执行：

```powershell
.\tools\run_teacher_samples.ps1 -ZipPath "D:\BaiduNetdiskDownload\测试文本.zip"
```

也可以指定解压和答案输出目录：

```powershell
.\tools\run_teacher_samples.ps1 `
  -ZipPath "D:\BaiduNetdiskDownload\测试文本.zip" `
  -OutputDirectory "$env:TEMP\teacher-paper-tests-3224004345"
```

## 数据完整性说明

对压缩包逐个检查后发现：

- `orig.txt` 和 `orig_0.8_add.txt` 是文本内容，但 `orig.txt` 内容存在明显乱码/错误编码痕迹；
- `orig_0.8_del.txt`、`orig_0.8_dis_1.txt`、`orig_0.8_dis_10.txt`、`orig_0.8_dis_15.txt` 的文件开头是 `<!DOCTYPE html>` 和 GitHub 页面内容，不是论文正文；
- 压缩包中还包含 `*_answer.txt`，这些是本地运行生成的答案文件，并非原始输入样例。

因此，文件名中的 `0.8` 不能直接当作本项目必须输出的标准答案。只有在拿到干净的原始论文文本和老师明确的期望答案后，才能进行算法口径校准；当前记录不擅自修改算法来迎合损坏或不完整的输入。
