# 论文查重程序设计说明

## 设计目标

程序接收原文、疑似抄袭文本和答案文件三个路径，计算两个文本的重复率，并把 `0.00` 到 `1.00` 范围内的两位小数写入答案文件。运行时不访问网络，不读取命令行指定范围之外的文件。

## 模块接口

核心实现位于 `paper_checker.py`，入口位于 `main.py`：

- `normalize_text(text: str) -> str`：执行 Unicode NFKC 规范化、大小写归一并移除空白、标点和符号。
- `calculate_similarity(original: str, suspect: str) -> float`：计算规范化文本的一元组和二元组相似度。
- `run(original_path, suspect_path, output_path) -> None`：完成读取、计算和结果写入。
- `main(argv: Sequence[str] | None = None) -> int`：校验参数，转换异常为稳定的进程退出码。

## 算法

对两个文本分别构造字符一元组和相邻字符二元组的多重集。每一组使用 Sørensen–Dice 系数：

```text
Dice(A, B) = 2 * |A ∩ B| / (|A| + |B|)
```

交集按字符片段出现次数的较小值累计。长度允许时，最终重复率为 `0.2 × 一元组系数 + 0.8 × 二元组系数`；短文本退化为一元组系数。该方法不依赖中文分词词典，对局部增删改和段落移动保持确定性。

## 数据流

```mermaid
flowchart LR
    A[命令行的三个路径] --> B[读取两个输入文件]
    B --> C[文本规范化]
    C --> D[一元组和二元组统计]
    D --> E[加权 Dice 相似度]
    E --> F[格式化为两位小数]
    F --> G[写入指定答案文件]
```

## 异常策略

- 参数数量错误：输出用法，退出码为 2。
- 输入不存在、不是普通文件、无法读取或无法解码：输出单行错误信息，退出码为 1。
- 输出路径无法写入：输出单行错误信息，退出码为 1。
- 成功：退出码为 0。

程序先读取两个输入，再打开输出文件，因此输出路径与输入路径相同时仍能完成当前计算。
